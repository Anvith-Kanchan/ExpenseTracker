# ExpenseTracker

A polished, offline-first Android expense tracker built with Kotlin + Jetpack Compose.

## Features
- Monthly spending dashboard and budget progress
- Quick expense entry
- Searchable expense history with filters
- Category breakdowns and insights
- UPI / Card / Cash tracking
- Dark mode
- Local-only demo data and no network dependency

## Build
Use Android Studio or GitHub Actions with JDK 17.

```bash
./gradlew assembleDebug
```

The APK is generated at `app/build/outputs/apk/debug/app-debug.apk`.
